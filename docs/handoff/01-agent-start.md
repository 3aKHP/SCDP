# 维护者接手指南

先读根目录 README、AGENTS、STATUS 和 .gitignore，了解当前能力、协作约定和公开边界。

- 使用或复现问题：从[使用指南](../guides/README.md)选择任务。
- 修改实现：核对[接口参考](../reference/README.md)、[架构](../design/README.md)和相关测试。
- 修改文档：遵守[文档规范](../dev/documenting.md)，同步所有入口和引用。
- 修改契约：核对[正式 schema](../../schemas/README.md)、[术语表](../glossary.md)及 [ADR](../dev/adr/README.md)。

一期执行计划已归入[历史资料](../history/phase-one/README.md)。后续任务以 STATUS 和当前用户授权为准，不重复执行历史部署步骤。

本机存在 local_dev/README.md 时按其说明查找忽略的研究原件和辅助仓库。公共流程不得依赖这些私有材料；跨仓库工作先读取目标自己的约定。凭证与真实正文不写入公开日志。
