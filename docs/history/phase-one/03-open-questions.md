# 来源边界与后续验证

一期实现和逐项验收进度由 [STATUS](../../../STATUS.md)维护。本页记录来源能力的边界与后续验证任务；这些边界在包内以未解析状态、覆盖报告和来源身份表达。

## 来源与消费边界

| 项目 | 当前处理 | 后续任务 |
|---|---|---|
| 官方语义目录 | 官方资源清单用于发现；独立公开来源提供部分标题、角色、卡片和衣装信息 | 扩展匿名语义来源，核对活动身份、顺序、解锁条件及剧情关联 |
| say Halo 路线身份 | 全部范围内正文保留，共享引导与路线归属分别表达；不推断未证实的完整目录 | 用明确来源核对角色路线身份，继续保留未知归属 |
| 版本参数 | `?v=` 随来源版本保存；前后主清单及全部分片复核提供观察窗口保证 | 长期核对 CDN 更新与缓存行为，不将参数视作不可变旧内容地址 |
| 未升版本修订 | 定时轮转检查分片和正文，内容摘要变化触发新发布修订 | 记录真实漂移事件与发现延迟，按预算调整复核覆盖周期 |
| 完整历史 | 当前选择集、已知译文种子、语义种子与历史退役分别审计 | 获取其他有明确来源的历史种子；当前清单不能证明完整游戏历史 |
| 控制语义 | 保留全部原帧、选项与跳转；条件两侧和重复标签首次目标有明确规则 | 新命令或外部状态继续保留证据，经验证后扩展语义 |
| 译文与元数据 | 固定独立身份；缺译、重复句歧义、标题冲突和未知关联进入报告 | 增补有来源的人工译文与元数据；AI 译文须使用独立来源类型 |
| 多媒体内容 | 首期提供全类型目录、依赖和表示契约，未下载内容保持 inventoried | 分类型验证定位、真实 MIME、编码、Spine 依赖、容量及 idolum 布局 |
| idolum 生产消费 | 当前 Line／Episode 契约使用合成样例验证，分支上下文独立保留 | 按 idolum 自身契约实现生产导入、经历筛选和后续多媒体接入 |

缺译与非关键元数据未知不减少正文范围。正文遗漏、获取失败、包损坏和错误依赖仍按[验收矩阵](07-acceptance.md)阻止发布。

## 指标口径

- 候选路径、可读剧情、独有正文和完整章节分别统计，不据重复内容删除原件。
- 译文发生位置覆盖、剧情范围覆盖和元数据覆盖分别报告。
- 当前可发现、实际获取成功和历史可恢复分别表达。
- 原始传输实体、解码内容、结构化记录、阅读文档和消费者索引分别追踪身份。
- 发布包、消费者活动版本和调度运行各有回执；上传成功不能替代实际消费验收。

后续实现保持当前授权范围，按[工程任务](05-engineering-work.md)、[数据任务](06-data-work.md)和[上线规程](08-launch-operations.md)维护相同门禁。
