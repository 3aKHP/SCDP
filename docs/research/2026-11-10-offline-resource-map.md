状态：2026-11-10 固定快照的离线分析。未发起网络请求，尚未验证全量文件内容或实际可用性。机器可读结果、输入大小与 SHA-256 见 [分析摘要](evidence/offline-resource-map-summary.json)。原始研究边界见 [来源评估](2026-11-10-assessment.md)。

## 目录覆盖

读取全部 393759 个路径及整数版本，按前两级路径分为 170 组。将路径中的连续数字替换为占位符，得到 5872 种词法模板。分组与模板两种统计的路径总数均与输入一致。模板仅用于缩小审阅范围；数字片段的业务含义、不同目录的编号关联仍需来源证据。

| 顶层目录 | 路径数 | 当前解释范围 |
|---|---:|---|
| sounds | 278406 | 声音目录；按子目录继续区分语音、音乐与音效 |
| images | 78929 | 图片目录；卡图、背景和界面用途由子目录及客户端引用验证 |
| spine | 17282 | 骨架、atlas 与纹理的候选组合 |
| json | 11000 | 排除 64 条 support_skills 后为 10936 条剧情候选 |
| movies | 3398 | 视频候选 |
| ae | 2527 | 动画相关目录，格式和依赖待验证 |
| particles | 2213 | 粒子效果相关目录，格式和依赖待验证 |
| fonts | 4 | 字体候选 |

Spine 共有 5755 个文件父目录，每个都包含 data.json、data.atlas 和 data.png，另有 17 条其他文件路径。这只能证明目录共现；atlas 页名、真实 MIME、多页纹理、实体归属和依赖完整性尚未验证。

完整的两级目录表、版本分布、代表路径和模板表保存于本地分析产物。复算方法为：对固定索引按上述规则分组，分别求和核对输入总数；原件继续留在忽略目录。

## 文本体积

容量使用十进制 MB。分别记录上游传输正文、解码内容和最终消费包；三者不能互相代替。

| 已有输入或实验 | 观察值 | 限制 |
|---|---:|---|
| 固定汉化来源完整 tar.gz | 45.85 MB | 包含剧情 CSV 以外的内容 |
| 归档内 5623 份剧情 CSV | 31.86 MB，未压缩 | 描述现有译文库存，非全部官方剧情 |
| 三份有传输记录的官方剧情 | 每份 815–4568 字节 | 非随机样本，未包含请求、TLS、代理及重试开销 |
| 六份本地剧情 JSON | 每份 2966–40992 字节 | 解码原件，包含场景控制等字段 |
| 六份文本与控制字段投影 | 每份 gzip 后 392–2405 字节 | 仅体积探针，非正式格式或保真验收产物，未加入译文和完整元数据 |

投影体积探针保留 id、speaker、text、select、label、nextLabel，使用紧凑 JSON 与 gzip；原件未修改。正式包须按剧情契约保留完整正文与控制证据，不能据此探针裁减正式数据。

以下仅为预算情景计算，分母为 10936 条候选，假设每条平均压缩传输正文相同：

| 假设均值 | 总正文大小 |
|---|---:|
| 5 KB | 54.68 MB |
| 10 KB | 109.36 MB |
| 25 KB | 273.40 MB |

这些情景不是预测或上界。最终双语文档包还受元数据、分支表示、重复正文、索引和压缩方式影响，须以构建后的实际字节数及摘要核验。纯文本的现有观察支持先评估文本产物的成本，媒体内容另行预算。

## 待验证问题与最低输入

按来源缺口选择样本，优先使用本地材料；本表是后续研究清单，未执行联网验证。

| 问题 | 优先离线证据 | 必要时的联网范围 |
|---|---|---|
| 路径模板如何定位实际 URL | 已存客户端 JS、来源固定的参考代码 | 每种未确认解析规则的少量代表文件 |
| 编号代表角色、卡片还是衣装 | 已存元数据、汉化快照、客户端引用 | 对应实体的小型语义记录 |
| 剧情关联哪些媒体 | 已有原始帧及路径目录 | 只补无法解释的引用样本 |
| Spine 依赖与真实格式 | 目录共现、已有消费者研究 | 少量 atlas、骨架，必要时纹理 |
| 全量文本获取需要多少流量 | 现有传输记录、各剧情类别计数 | 按类别分层抽样，先检查缓存并设硬预算 |
| 最终文档包是否适合本机下载 | 构建产物大小、文件清单与摘要 | 选择纯文本压缩包，下载后核验 |

未来采集器需实现共享总字节预算、单文件上限、请求与重试上限、流式中止和断点缓存。失败与重试纳入计数，并为在途数据和协议开销预留余量。现有研究脚本尚未具备这些预算控制。
