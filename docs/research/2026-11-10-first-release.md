## 正文、译文和元数据

逐条验证全部 10936 篇与 379475 处正文发生位置；另有 19 处未知字符串证据保真保留。原件有 10891 个不同解码摘要、10118 个不同顺序正文签名，未据重复内容裁剪剧情。空正文数为零。

全部原帧和 25934 处控制证据保留。阅读状态条件跳转同时表示真分支与顺序路径；重复标签按已核对的客户端规则指向首次声明，并保留所有标签位置。短剧情、选择、失败路线及互斥正文均进入 collection。

中文对齐 245688 处（人工来源 242227、通用回退 3461），歧义 53 处，缺译 133734 处。译文固定独立来源提交，原文修订重新核对发生上下文。

语义来源提供 28 个角色、1470 张卡片和 998 套衣装实体。剧情标题唯一候选 6314 篇、冲突 854 篇、未解析 3768 篇；角色关联已知 10536 篇，卡片关联与完整顺序等字段覆盖仍有限。全部缺口、冲突、推断来源和未匹配种子在包内报告。

覆盖口径为当前官方选择集及已知历史种子，不宣称恢复完整游戏历史。媒体提供目录、依赖与表示契约，首版未下载媒体内容。idolum 当前真实数据类通过合成契约检查，其生产激活不属于本次门槛。

## 消费、恢复与调度

原生 MCP-KB staging 通过完整安装、同包重装、安装文件摘要与 404343 个索引块的非空正文行对账。生产切换保留完整前代，其他 collection 摘要保持不变。

生产实际 MCP HTTP 完整读取 10936 篇、13234 页、6114581 行，逐行与产物一致。原文与已有中文的检索、分块读取、目录、大纲和 grep 通过；外部 HTTPS 入口及管理员／普通角色边界另行验证。

恢复证据包括发布指针切换前进程退出、截断包拒绝、原生导入中断、错误基线拒绝、激活失败恢复和进程中断恢复。隔离环境完成原文修订、仅译文更新及连续三代回退；生产实测停用首版、恢复完整前代，再重新激活并重复完整协议验收。

上线观察先以一分钟周期执行 3 次实际定时检查，均记录 unchanged；之后设置为十分钟稳态周期。另对真实 worker 进行受控中断和重启，检查点、累计账本及互斥锁恢复通过。发现到激活的延迟取决于实际获取与全量验证时间，十分钟仅表示检查频率。

G0–G10 均有实际证据。回执、进程日志和私有部署映射留在忽略工作区；操作及恢复命令见[运维指南](../dev/operations.md)。
