# 消费者适配

当前可用接口与环境前提见[集成指南](../guides/integrations.md)。SCDP 标准包独立于消费者的运行数据库和权限配置。

## 已实现边界

MCP-KB 适配提供 collection 生成、隔离安装、索引覆盖检查、协议验证以及带恢复记录的消费切换。源资料保留全部正文和分支，消费者索引可重建。

idolum 适配提供 Line／Episode 的预览投影和合成兼容校验。投影将分支证据保留在独立结构中，不执行生产导入或向量化。当前未完成 idolum 生产激活。

## 后续集成

idolum 的角色映射、失败路线筛选、互斥经历处理和嵌入由其消费策略决定。标准包保持全部正文，不能根据单个消费者的经历筛选裁剪归档。

媒体接入需要先完成真实资源定位、依赖闭包、编码和容量验证；衣装选择、缩略图风格、上传与缓存属于消费适配。Python 与未来 Go 后端通过语言无关契约接入，不依赖 SCDP 内部对象。

此前源码调查与任务要求见[一期历史材料](../history/phase-one/01-agent-start.md)。当前兼容状态见 [STATUS](../../STATUS.md)。
