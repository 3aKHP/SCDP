# 数据契约

正式字段、必填性和枚举由[契约 v1](../../schemas/README.md)维护；包布局见[参考](../reference/package.md)。本页解释模型职责，不另建候选字段表。

## 身份与版本

Asset 使用稳定逻辑身份，AssetVersion 记录来源版本和字节表示。相同路径的新内容生成新版本；原件、解码产物和阅读文档各有摘要。Snapshot 标识构建输入，发布顺序由 releaseSequence 和 publicationRevision 表示。

当前只发布完整快照，不支持增量基线。未知类型保留原值，未知语义使用 null 或 unresolvedFields；不能把未下载媒体标成可用内容。

## 剧情与译文

Story 保留原始帧、正文发生位置、选项、控制证据与资源引用。发生位置使用 JSON Pointer，不以可能重复的游戏帧 ID 作为唯一键。条件跳转保留两侧路径，未知控制继续保留证据。

Translation 按剧本、发生位置、原文摘要和上下文关联，记录来源文件及身份。歧义保留候选，缺译保留日文；通用回退与同篇对齐分别标记。当前仅整合已有译文，不生成 AI 翻译。

## 元数据与依赖

Entity 和 Relation 表达角色、卡片、衣装与剧情关联；第三方数据与推断关系记录来源和确定性，未知标题与归属不伪装成官方事实。Asset 依赖和表示形式容纳后续媒体，内容下载支持范围见[多媒体](03-multimedia.md)。

## 消费兼容

消费者检查主版本、实际能力和必需依赖。索引和运行数据库由消费者自行构建，不作为 SCDP 的标准交换格式。格式变化需同步 schema、示例和兼容测试，并按 ADR 记录决定。
