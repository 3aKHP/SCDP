# 0004 — 阅读段落与公开 collection

决定日期与记录日期：2026-11-10。

## 背景

逐帧 Markdown 标题使按标题切片的消费者产生大量短块，邻近对白缺少共同检索上下文。v0.1.0 的 10,936 篇阅读文档在实际 KB 解析器中产生 404,343 个切片。

维护者授权优化阅读格式，并将闪彩 collection 设为 Public。

## 决定

普通帧使用加粗帧标记，同段保留邻近对白。首个可见帧、包含控制证据的帧以及控制帧后的下一可见帧开始新的二级标题段。选择、标签、跳转、条件与未知控制保留独立边界；段落提示按原件顺序展示，不代表连续发生的经历。正文、翻译状态、发生位置和控制证据保持完整。

这是阅读表示的变更，原始 JSON、标准记录及 schema 不变。构建代码身份参与快照身份；同一上游输入使用新的 publicationRevision，旧包不覆盖。

新生成的闪彩 collection 使用 `visibility: public`，包 scope 同步声明公开。KB 的 Public 表示已认证普通用户可见；服务鉴权、其他 collection 权限及受控下载服务保持独立。第三方内容权利继续按 [NOTICE](../../../NOTICE.md)管理。

## 取舍与验证

仅把全部帧标题改为普通文本，在相同语料上可降至 19,743 个切片，但不保留控制段边界。采用控制边界后为 65,436 个切片，减少约 83.8%；这是固定 v0.1.0 语料的离线测量，不是线上新快照的承诺值。

合成检索对照使用实际 KB 索引器：相邻对白的两个检索词能在同一块命中，分支两侧仍分开。KB 当前多词查询使用 OR 并按匹配词数排序，因此旧格式不必然导致零结果；此次改善的是共同上下文与匹配完整度。日文与中文检索均保留。

发布前逐条验证原件、结构化记录、译文和全文覆盖，隔离重建全库索引并检查其他 collection 不变，再执行生产协议验证和普通用户权限检查。失败恢复前代；索引重建后旧 chunk ID 不保证稳定，引用应使用文档路径与原件位置。

本决定更新 [ADR-0003](0003-public-distribution-and-notice.md) 的消费可见性策略；历史包中的初始 private 字段保持原字节。
