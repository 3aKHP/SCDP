# 0002 — 历史正文、内容修订与消费切换

决定日期与记录日期：2026-11-10。

## 背景

官方清单不能证明同号正文没有变化；消费者还需要在原文、译文和目录独立更新时保留可靠的恢复入口。
MCP-KB 使用独立的 sources 与 SQLite 索引，两者须在明确的维护窗口协调切换。

## 决定

构建输入身份包含所有已选原件与解码摘要、目录历史、各独立来源身份、代码与 schema 摘要。
同号正文漂移生成新内容身份；旧获取记录及内容对象保留。源更新推进发布序号，同来源修订推进 revision。
发布目标使用独立互斥锁，拒绝低序号激活及同一身份覆盖。

历史目录保留 firstSeen、lastSeen 与最后来源版本。源移出的可用正文继续进入阅读包，标为 historical；
仅有目录的历史记录单列，不声称已恢复。当前选择集与历史范围分别统计，空文本和未知字符串证据单列。

MCP-KB 候选复制当前资料并保留其他 collection，使用原生工具导入和旁路建索引。
完整摘要与索引对账通过后，参与部署者共享锁，停止服务，保存旧资料与索引，切换到候选，再恢复服务。
启动失败自动恢复；进程中断可从恢复日志及实际文件状态恢复前代。协议验收失败由部署消费者调用回退。
恢复目录保留完整旧资料树，包括其原有原生安装备份；实际位置由恢复回执给出。

自动循环每轮检查官方来源、独立译文和元数据，轮转复核分片及正文；无变化仅记录心跳。
首次正式激活与三次定时观察仍须按一期门槛提供真实证据。

## 后果与验证

完整候选与旧代同时保留，需要按实际包、资料和索引大小预留磁盘。首期不自动垃圾回收。
私有文件分发使用管理员身份和回环监听；远程访问采用部署者已授权通道。

验证入口：history、cycle、activation、distribution 合成测试，以及实际 MCP-KB 原生 CLI 的隔离升级演练。
操作入口见[运维指南](../operations.md)。正式执行状态见 [STATUS](../../../STATUS.md)。
