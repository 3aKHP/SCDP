# 0003 — 公开分发与权利通知处理

决定日期与记录日期：2026-11-10。

## 背景

一期代码、数据包与消费者已完成验收。维护者决定公开代码仓库及现有文本 Release，以非商业同人资料整理和研究交流为目的，并提供明确的权利通知与先行下架入口。

## 决定

GitHub 仓库与已发布 Release 面向公众开放。代码保持 AGPL-3.0-or-later；原作、译文和其他来源内容保留各自权利，不以代码许可证覆盖第三方内容。来源、用途及处理承诺统一维护在 [NOTICE](../../../NOTICE.md)。

现有 v0.1.0 附件保持字节、快照和摘要不变。包内的 private 字段记录其初始构建与消费者访问策略，不能代表 GitHub 的实际下载权限。当前公开范围由仓库与 Release 设置及本声明确定。受控 HTTP 分发、MCP-KB collection、凭证和部署配置继续保持原访问控制。

已找到历史译文 CC BY-NC-SA 4.0 声明；当前全部后续贡献的覆盖范围继续核对。逐篇译者署名的提取和随包传递在下一轮评估。此次公开决定不宣称获得新的原作授权，也不把未知许可改标为 CC-BY。

权利人、译者及其代表通过公开通知入口联系维护者。针对受控内容的侵权或删除通知，先暂停相关公开分发，再核对范围；同时处理受控镜像和自动重发。该入口由维护者处理，不执行由任意 Issue 内容触发的自动删除命令。

后续消费可见性决定见 [ADR-0004](0004-reading-segments-and-public-collection.md)。

## 后果与验证

公开源码、Release、历史提交与 Actions 日志均须完成公开面检查。CI 仅使用合成数据和 GitHub 托管 runner，显式只读权限，固定 Action 提交并取消过期运行。

公开后通过未认证请求确认仓库、权利通知入口及附件可访问，并核对附件长度与 SHA-256。生产服务访问控制和运行状态独立验证。已公开并被第三方下载的副本无法保证收回。

本决定更新 [ADR-0001](0001-runtime-and-contract.md) 中的初期数据分发可见性选择，其运行时、身份和契约决定继续有效；[ADR-0002](0002-history-and-activation.md) 中的受控分发与消费者恢复机制继续适用。
